## 📋 Descripción

**BP-ANN** es un proyecto de investigación que implementa redes neuronales artificiales para la estimación no invasiva de presión arterial a partir de señales de fotopletismografía (PPG) y electrocardiografía (ECG). Este trabajo forma parte de un Proyecto Final de Bioingeniería de la Universidad Nacional de Entre Ríos (UNER) y propone un enfoque innovador combinando arquitecturas tradicionales con técnicas de meta-aprendizaje.

### Características Principales

- 🧠 Múltiples arquitecturas de redes neuronales convolucionales
- 📊 Procesamiento avanzado de señales PPG y ECG
- 🔄 Implementación de meta-learning con Few-Shot Learning
- 📈 Evaluación de modelos y metamodelos bajo particion aleatoria de datps y por sujeto
- 🎯 Estimación de presión sistólica (SBP) y diastólica (DBP)
